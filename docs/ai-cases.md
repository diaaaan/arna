# Ручные AI-кейсы

Этот набор используется для ручной проверки Mind Engine. Ожидания относятся к prompt version 3 и локальному временному контексту `Asia/Almaty` на момент анализа.

Для относительных периодов принято: `через неделю` означает текущую локальную дату плюс семь дней, а `на следующей неделе` без конкретного дня — понедельник следующей календарной недели.

## 1. Список покупок с количеством и срочностью

Ввод: `Купить шампунь 3 срочно`

Ожидание:

- type: `shopping_list`;
- category: `home`;
- urgency: `high`;
- items: `шампунь ×3`;
- dueDate: `null`.

## 2. Короткая неоднозначная команда

Ввод: `Убрать точки`

Ожидание:

- type: `task` или `unknown`;
- category: `unknown`;
- urgency: `unknown`;
- dueDate: `null`;
- confidence: низкая, ориентировочно `0.3–0.5`.

## 3. Ближайшая будущая пятница

Ввод: `До пятницы закончить экран ребёнка`

Ожидание:

- type: `task`;
- category: `work`;
- dueDate: ближайшая будущая пятница относительно переданной локальной даты;
- если анализ выполняется в пятницу, dueDate указывает на следующую пятницу.

## 4. Завтра по Asia/Almaty

Ввод: `Разобрать стол завтра`

Ожидание:

- type: `task`;
- category: `home` или `personal`;
- dueDate: завтрашняя дата в формате `YYYY-MM-DD` по `Asia/Almaty`.

## 5. Явно сохранённая фраза

Ввод: `Мне понравилась фраза: тек токтама`

Ожидание:

- type: `quote`;
- category: `personal` или `unknown`;
- urgency: `unknown`;
- items: `[]`;
- confidence: высокая.

## 6. Проект без конкретного следующего действия

Ввод: `Сделать сервис доставки еды для офисов`

Ожидание:

- type: `project`;
- category: `work`;
- urgency: `unknown`;
- dueDate: `null`;
- фраза описывает значительную многоэтапную инициативу, а не одно завершаемое действие.

## 7. Действие с рабочим контекстом

Ввод: `Убрать точки в макете детского профиля`

Ожидание:

- type: `task`;
- category: `work`;
- urgency: `unknown`;
- confidence: высокая.

## 8. Возможность как идея

Ввод: `Можно сделать сервис доставки еды для офисов`

Ожидание:

- type: `idea`;
- category: `work`;
- urgency: `unknown`;
- dueDate: `null`.

## 9. Явно названная идея

Ввод: `Идея сервиса доставки еды для офисов`

Ожидание:

- type: `idea`;
- category: `work`;
- urgency: `unknown`;
- dueDate: `null`.

## 10. Конкретный следующий шаг сегодня

Ввод: `Сегодня начать прототип сервиса доставки еды`

Ожидание:

- type: `task`;
- category: `work`;
- dueDate: текущая локальная дата по `Asia/Almaty`.

## 11. Гипотеза приложения

Ввод: `А что если сделать приложение для подсчёта калорий`

Ожидание:

- type: `idea`;
- category определяется независимо от типа и может быть `health` или `unknown` в зависимости от уверенности контекста;
- urgency: `unknown`;
- dueDate: `null`.

## 12. Ограниченная сроком задача

Ввод: `Нарисовать экран детского профиля до пятницы`

Ожидание:

- type: `task`;
- category: `work`;
- dueDate: ближайшая будущая пятница относительно переданной локальной даты.
